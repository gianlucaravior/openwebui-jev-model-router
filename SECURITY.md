# Security Policy

## Supported Version

Security fixes are applied to the latest version on the repository's default branch.

## Reporting a Vulnerability

Do not disclose security vulnerabilities through public GitHub issues, discussions, or pull requests.

Use GitHub's private vulnerability reporting feature for this repository when it is available:

<https://github.com/gianlucaravior/openwebui-jev-model-router/security/advisories/new>

If private reporting is unavailable, contact the repository owner privately through their [GitHub profile](https://github.com/gianlucaravior) and avoid sharing exploit details publicly.

Include a clear description of the vulnerability, affected file and version, reproduction steps, potential impact, and a proof of concept where safe. Remove API tokens, credentials, user data, and private conversations from the report.

## Scope Notes

This filter handles Cloudflare API credentials and transmits routing data to Cloudflare. Reports involving accidental token exposure, request-data disclosure, unsafe logging, routing bypasses, or insecure request construction are especially useful.
